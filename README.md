# 研学台 StudyDeck

> 一个 AI Native 的专升本备考工作台：从「今天该学什么」到「这一讲听懂没有」到「错在哪」，全部由 Agent 在本机数据上编排；人不填表、不选菜单，只确认。
> 所有数字都能在本机数据里核对出来——捞不到证据就说捞不到，不编。

| | |
|---|---|

| 形态 | 单机 Web 应用：前端是界面，后端是 AI 接入层 + 本机数据层 |

## 1. 它解决什么问题

三个真实痛点（都可验证，不是编的）：

1. **课太多学不完** —— 889 讲、约 430 小时，人算不出该怎么排。计划页按考试日期和每天时长算出「每科能吃到第几讲、要砍掉哪些」，砍的每一条都带理由。
2. **听完就忘** —— 笔记、截图、词表散在 B 站、网盘、纸面上，没有一处能回看。课堂页按 S 键截帧打点，笔记挂在这一讲名下，画布页能整理成导图。
3. **AI 讲题不可信** —— 大模型爱编。讲题之前先在本机题库/讲义里捞证据，每段讲解挂引用、引文必须逐字命中原文；捞不到就明说「没有依据」。

## 2. 功能清单（都能点、都能落库）

- **课程主页**（首屏）：一进来先看总览——多少讲、多少小时、学到哪、这一讲接着看什么、哪几章、有哪些题源；右栏是家底、走完多少、缺什么
- **今日**：主行动 + 今日队列，四格 KPI 点了直接去干活
- **课堂**：讲节目录（889 讲按章分组可跳）+ 本地视频 / B 站播放 + 词群 / 讲义 / 当堂测 / 提问四个侧舱 + 截帧打点
- **课程库**：五科课程卡片（计算机 200 分 / 英语 / 高数 / 政治 / C 语言）
- **背单词**：四选一 → 默写 / 挖空 / 看中写英，答错回炉，SM-2 间隔重复，复习队列与今日到期
- **练习**：8 个题源（语法 781 题 / 985 道真题 / 505+613 条考点卡 / AI 生成题），题号翻页、跳题号、每组题数可调；判分、解析、错因打标
- **考场**：15 套可判分真题卷，分题型作答交卷算分；AI 组卷（真题优先，AI 题逐题标注）
- **统计**：只显示能核对的量；没数据就写没有，不估算
- **作文**：13 道真题作文 + 汉译英，AI 批改
- **画布**：本讲笔记导图引擎（自动布局、撤销重做、MD 导入、6 种导出、XMind 拉推）
- **助手**：一句话编排 163 个本机工具——找课、拉词书、排计划、批量入库；写盘前要确认

> 左侧栏按「课程 / 这门课 / 全部」三段组织：点一门课，课程主页、课堂、课表、背单词、练习整站跟着换科目，不用每页各选一次。

## 3. 技术架构

前端 Web 应用为主要呈现形态；后端只做「AI 接入层 + 本机数据层」。

```
┌────────────────────────── 前端（React 18 + TS strict，11 页）──────────────────────────┐
│ 今日  课堂  课程库  计划  背单词  练习  考场  统计  作文  助手  画布（自研导图引擎）     │
│ 设计系统 · 动效 · 流式渲染 · 思考可视化 · 错误兜底 · 三档响应式（1600/1280/1024）       │
└──────────────────────────────────┬──────────────────────────────────┘
                                   │  SSE 流式对话 / 工具调用   REST /api/tool/{name}
                                   ▼
┌────────────────── AI 接入层（Python FastAPI，只做四件事）──────────────────┐
│ ① 模型路由（自备 Key / WorkBuddy / Trae 三家出口，断网可降级）             │
│ ② 工具注册表（163 个；写盘工具必须自报干了什么，否则强制标 unknown）       │
│ ③ 上下文与证据（压缩、检索引擎；引文逐字命中原文才允许出现在讲解里）       │
│ ④ 本机数据层（SQLite + 文件；无账号、无云端、进度只存本机）                │
└──────────────────────────────────────────────────────────┘
```

三个创新点（逐条可验证）：

| # | 创新点 | 证据 |
|---|---|---|
| 1 | **证据优先的讲解**：先捞证据再说话，每段讲解挂引用，引文逐字命中原文 | `server/evidence.py`；讲解版本留档，同题重讲可对照 |
| 2 | **操作卡与批量闸门**：模型给出「点一下就执行」的按钮，同类动作 ≥2 门自动补「全部入库」 | `server/agent.py` 的 propose 链路；凑不出合法按钮就不给 |
| 3 | **真实性铁律**：页面每个数都能核对；写盘没自报就强制标 unknown | `server/tools.py` 的 `_WRITE_TOOLS` 兜底 + 全站无头探针 |

## 4. 安装运行

依赖：**Python 3.11+**（开发用 3.13）、**Node.js 20+**（开发用 22）、Git。

```bash
# ① 后端依赖
pip install fastapi uvicorn

# ② 配置：复制模板，填自己的模型 Key（不填也能跑：模型路由会走平台出口，界面如实标注用的是谁）
cp server/config.example.json server/config.local.json

# ③ 前端
cd app
npm install
npm run build        # 产物输出到 web/app-dist/

# ④ 启动（仓库根目录）
python -m server.main    # 或 Windows 直接双击 start.bat
# 打开 http://127.0.0.1:8770
```

- 无需注册登录；进度、作答、笔记全部存本机 `data/`（已被 .gitignore 排除，不入仓库）。
- `data/` 为空也能启动：界面会如实显示「这台机器上还没有题源/课程」，不会塞假数据。

> 仓库只放可运行的前后端源码与配置模板；设计文档、验收探针、课程素材与真实数据都在本机，不入库。

## 6. 测试与质量

- 开发期有 140+ 个无头探针：起真实服务、开无头 Chrome、断言界面真实行为（判分落库、题库翻页可达最后一题、弹层样式一致、全程无 console error）。
- 每项功能改完必须「构建 + 探针全绿」才算完成；探针结果不手填。
- 探针脚本依赖本机真实数据与路径，不随仓库发布。
- 前端 `tsconfig` 开 `strict`；后端写盘操作必须自报成效，不自报会被强制标 `unknown` 并显示在界面上。

## 7. 关于这个项目

个人项目，为专升本备考而写，自己每天在用。

- 代码按模块整理提交，不伪造时间线。
- 本仓库只放可运行的源码与配置模板；设计笔记、验收探针、课程素材与真实学习数据都在本机，不入库。
